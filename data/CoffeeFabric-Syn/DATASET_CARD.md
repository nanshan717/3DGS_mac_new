# CoffeeFabric-Syn (development dataset card)

CoffeeFabric-Syn is a synthetic benchmark under development for evaluating protective-
fabric reconstruction beneath coffee-inspired vegetation. P01 is a visual prototype and
must not be represented as a real coffee plantation capture or a finalized benchmark.

## Provenance

All P01 geometry and materials are created procedurally by the accompanying Blender Python
script. No downloaded meshes, textures, photographs, or generative-image assets are used.
The fabric deformation is generated independently of the Bernstein representation used by
BR-GS. Exact random seeds, Blender version, scene metadata and SHA-256 checksums accompany
each generated scene.

## Intended use

P01 is for visual review and pipeline validation. A frozen release will include independent
ground-truth geometry, fixed scene-level splits, failure cases and method-independent metrics.
Synthetic results must be reported separately from controlled real and field data.

## Licensing status

Dataset and generator licensing is intentionally marked as pending project/institutional
review. Do not publish the dataset under an assumed license until that review is complete.
